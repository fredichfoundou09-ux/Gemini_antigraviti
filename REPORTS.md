# Rapports

Module `/app/rapports` et `/app/partner/rapports`.

## Catégories
- Pédagogiques : effectifs, présences, absences, retards, notes, réussite.
- Financiers : factures, paiements, solde, rémunération enseignants.
- Administratifs : inscriptions, pré-inscriptions, utilisateurs, activité.
- Institutionnels : certificats, bourses, formations, partenaires.

## Exports
- CSV : `exportCsv()`.
- Excel simple : `exportJsonAsExcel()`.
- PDF : prévu via Edge Function pour rapports signés.
